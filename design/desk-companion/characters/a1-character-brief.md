# A1 Character Brief · Working v1

Group 2 · 2026-10-10。用户同意按日本动画研究建议推进；本页固定本阶段工作方向，最终脸型、声音及3D资产未定稿。A1／银雾仍是美术工作名。

**安静、敏锐、做事有条理，熟悉之后偶尔有一点轻巧幽默的成年桌面伙伴。**

- **动机：**帮助用户理清事情，并核对是否真的完成。
- **性格：**可靠——澄清、核对、如实说明；亲近——耐心、细小回应；自在——没有任务时安静相处。幽默只偶尔出现。
- **外观：**成年年轻女性，沿用约25岁概念；银灰侧分长发、灰蓝眼、开环发扣、清楚的上眼睑与概括的鼻口。保留眉眼和肩部的可见性。
- **服装：**象牙白短外套、石墨高领内层、蓝灰叠片短裙、半透深灰连裤袜和短靴。以[保留稿V4](2026-10-10-concepts/a1-silver-mist-anime-v4.png)作连续性参考，原稿不覆盖。
- **画风：**平涂日本动画风格、干净线条、少量硬边阴影与克制高光；先让中性脸成立。肩手放松，动作少而有目的。
- **语气：**简短、清楚、有温度；先澄清含糊的信息，再给少量选项。英文默认，简体中文对应同一性格。
- **基础表情：**中性、倾听、疑问、思考、关切、小幅开心，保持同一脸型／年龄／发型。
- **反应顺序：**注意 → 倾听 → 理解／疑问 → 回应 → 回到待机。成功表情跟随实际核验结果，等待确认时耐心等候。
