## 直接开始

- [完整演示包 ZIP](FYP_ArUco_full_demo_20261124.zip)，包含源代码、模型来源／许可、生成录像和操作说明。35.9 MB 的 YOLOX-S 权重首次按下方命令下载并校验，避免在源码及 ZIP 重复存储。
- [程序与所有文件](demo/) · [L 形三牌记录](demo/L形三牌记录说明.md) · [空白测量卡](demo/三牌测量记录卡_空白.txt)。
- [单页 A4 纸质定位牌](FYP_ArUco_paper_cutouts_A4_actual_size_20261123.pdf)：打印“实际大小／100%”，不要缩放，保留白边，先量 50 mm 校验线。
- [实际验证与边界](../../output/qa/2026-11-24-aruco-progress/verification.md) · [尺寸和相机说明](rig-arm-fit-and-camera.md)。

解压 ZIP，进入 `aruco_demo_20261123`；或在仓库进入本目录的 `demo/`，使用 Python 3.11／3.12：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python download_model.py
.venv/bin/python app.py --open
```

Windows 对应使用 `py -3.12 -m venv .venv`、`.venv\Scripts\python.exe -m pip install -r requirements.txt` 、`.venv\Scripts\python.exe download_model.py` 和 `.venv\Scripts\python.exe app.py --open`。网页地址 `http://127.0.0.1:8767/`，服务仅监听本机。Mac 安装依赖后可双击 `启动定位台.command`。模型首次下载需要网络；之后本地推理不需要云端 API 或密钥。iPhone 可通过 Mac 连续互通相机作为浏览器摄像头输入；镜头、支架和授权需要各自现场确认。

## 当前功能

| 功能 | 已完成的行为 | 使用条件 |
| --- | --- | --- |
| 相机／录像与证据保存 | 摄像头选择、图片／录像导入、暂停、轨迹、录制 MP4 或 WebM、CSV 导出 | 浏览器相机授权；所有生成素材保留 SYNTHETIC 标识 |
| 免测量模式（默认） | 唯一 ID 4 可见即可显示像素位置和画面方向 | 单位 px，不输出物理桌面厘米坐标 |
| L 形三牌 | ID 0 近左、ID 1 近右、ID 2 远右，填 A=0→1、B=1→2 两段中心间距（cm） | 直角 L、黑框 6 cm、图案朝向一致、同高；ID 3 不参与也不替代缺牌 |
| 四角／高级标定 | 四码中心映射；可选三牌十二角点备用；按长深和距边生成预定码心坐标 | 按实际摆放量测；改尺寸不是自动测量现场位置 |
| 物品与未知变化 | 本地模型识别 17 类物品；圈定区域、记录空桌后检测一般变化 | 阴影、反光和细小／透明物可能误报或漏检 |
| 接近与边界提示 | 近障黄色、识别框重叠／越界红色，丢失单列无法判断 | 图像像素距离和候选框，不是实际物理间距，也未驱动停车／绕障 |

L 形模式在页面以厘米显示，API／CSV 物理坐标仍为毫米；最新网页 CSV 为 37 列。CLI 原入口 `aruco_demo.py` 保留 7 列导出，勿混用格式。标定及模式可在当前浏览器保存、刷新恢复；换浏览器不共享。

## 五块纸牌与桌面

字典 `DICT_4X4_50`。ID 0–3 黑框各 60 × 60 mm，含白边裁剪各 80 × 80 mm；ID 4 黑框 40 × 40 mm，含白边约 53.33 × 53.33 mm。五张先平放、保持图案面同高，以手动移动 ID 4 验证。实际桌面 1500 × 650 mm、板厚 25 mm；L 形两段距离定义的是测试矩形，不等于整张桌子。
