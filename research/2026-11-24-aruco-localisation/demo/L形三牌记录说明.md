# L 形三牌：只记两段厘米距离

适用于相机看得清 ID 0、1、2，ID 3 不在画面内的情况。原来的免测量像素模式和高级四角设置仍保留。

## 摆好三张固定牌

```text
远侧 ↑（所有参照牌图案的上边朝这里）

                  ID 2
                    │
                    │ B：中心到中心
       ID 4 在这里移动
                    │
ID 0 ──────────── ID 1
    A：中心到中心
靠近你的一侧
```

0、1 左右对齐，1、2 前后对齐，两段成直角。三张牌平放，五张牌首次测试保持同一高度。参照牌图案不能随意旋转，保留白边。ID 4 可以移动、旋转；ID 3 不参与这个方法，也不能替代缺失的 0、1、2。

## 只量两段

- A：ID 0 的黑框中心到 ID 1 的黑框中心，单位厘米。
- B：ID 1 的黑框中心到 ID 2 的黑框中心，单位厘米。

量中心，不量纸边，不用填写 X/Y，不用量整张桌子。比如实际量到 60 cm 和 30 cm，就填写 60 和 30；示例不是预设的实测值。

点页面右上“桌面标定”，选择“L 形三牌：只量两段”，填好 A、B，再点“保存并开始三牌定位”。程序自动换算、切到厘米位置显示，且保存到当前浏览器。重新打开可继续使用；换浏览器不会共享记录。可点“下载这份测量记录”保存文字记录；下载本身不应用设置。

“纸牌尺寸”折叠项通常不用改：本包 A4 参照码按 100% 实际大小打印后，黑框边长是 6 cm，不包括白边。若缩放打印，需填实际黑框边长；纸不能翘曲。

## 怎么读结果

ID 0 中心为起点。左右位置为向右的距离，前后位置为向远侧的距离，显示单位 cm。ID 4 在移动时位置和轨迹跟着更新。参照牌 0、1、2 的数值来自测量记录，ID 4 的数值才是视觉计算结果。ID 3 不显示虚构的厘米位置。

两段距离定义的是三牌围出的矩形测试区域，不是整桌边界。超出这个区域会提示“测试区域”越界。要监测实际可见桌边，另外点“标出桌面范围”圈四角。边界和障碍提醒仍是图像提示，没有连接小车停车或避障。

CSV 继续保持 37 列：`x_mm`、`y_mm` 保存毫米，界面的厘米是显示换算，不改变导出列的单位。像素模式的毫米列仍留空。

## 还定位不到时

先检查 0、1、2 是否都识别；随后检查 L 形直角、中心间距、三张牌朝向一致及黑框边长。程序仍检查三牌的 12 个角点，不会把随意摆放的三张牌假装换算成准确厘米。

可先用较小区域验证；不一定要铺满 150×65 cm 的整张桌子。若暂时不测量，切“免测量演示 · 像素轨迹”即可只跟踪 ID 4；此时不代表真实厘米位置。

## 验证边界

此更新通过生成图／生成录像、接口和浏览器交互测试，包括记录恢复、厘米显示、37 列 CSV 及三牌移动轨迹；不是实际 iPhone、纸牌或整机精度验收。现场需用尺对照几个 ID 4 位置，再记录误差。
