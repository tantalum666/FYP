# 2026-11-23 程序验证范围

使用 Python 3.12 和 OpenCV 4.13.0，在人工生成的透视图及 60 帧生成录像上验证。旧 A4 打印页的 ID 0–4 编码逐格与 OpenCV `DICT_4X4_50` 对照一致。测试覆盖 3 个位置、4 个朝向、逐个参照遮挡、目标遮挡、重复 ID 和恢复。视频入口完成 45 帧正常跟踪、5 帧目标丢失、5 帧参照缺失、5 帧重复 ID，丢失位置在 CSV 中留空。

新增本机网页操作界面，复用相同的 OpenCV 检测与坐标函数。已在浏览器实际点选生成样本、导入 MP4、暂停、校验并应用标定、录制与导出 CSV。浏览器录制文件可用 OpenCV 解码 177 帧 1440 × 810 画面，实际导出 CSV 含 182 条有效坐标。小于桌角坐标的桌面长度会被标定校验拒绝。

此结果验证程序处理生成输入的行为。尚未读取真实摄像头、测试学校打印的牌，或验收桌面实测精度。相机权限和实际镜头仍须在现场确认。初次演示须按《使用与测试说明》记录实际数据，生成录像及截图均保留 SYNTHETIC 标签。

## 五牌坐标、手机接入与三牌备用

网页新增每张码的图像中心和桌面坐标表，CSV 共 27 列。ID 0–3 明确标为标定参照，ID 4 为视觉计算。浏览器导出的 155 行样本 CSV 经过解析，ID 4 的 X 从约 350 到 1130 mm 变化；缺失牌坐标留空，两个 JSON 字段均能正确读取。新版本短录制生成 MP4 并成功解码 3 帧 1440×810；此前 177 帧录制为旧界面测试，不混作本次新录制。

三参照为明确开启的备用模式，用已知黑框边长和统一朝向的 12 个角点拟合，不用三个中心假装完成透视校正。12 张生成透视图覆盖任意一张参照缺失、三个目标位置；最大生成位置误差约 2.185 mm。两张参照和错误朝向被拒绝。浏览器实际应用三牌设置并用缺少 ID 3 的生成图显示了 ID 4 坐标。此误差不是实物精度。

已增加摄像头列表刷新、切换后重新采集和断流清空，iPhone+Mac 通过 Apple 连续互通相机接入。用户确认同一 Apple 账户。没有连接或授权真实 iPhone 摄像头，手机画面、支架高度、整桌视野与现场坐标精度仍待用户实测。

## 桌面物品

公开照片中实际识别出笔记本电脑和水杯；把同一照片放进生成的参照牌画面后，两类物品均显示识别框、列表及桌面投影。API 检查包含无牌仍识别、参照齐全时投影、ID 4 丢失仍能投影、参照不足时清除投影、关闭识别、空白帧及非法阈值。浏览器核对物品开关、五牌与物品同屏、27 列 CSV 含两件物品及其投影 JSON。

COCO128 的闭合电脑和画面内过小的电脑样本有漏检，不能宣称所有电脑姿态都可识别。物体高度会影响二维框的投影；此版本未接小车规划、自动绕障或防跌落。

## 免测量像素模式与本次标定提示修复

用户实拍截图能识别 ID 0、1、2、4，但没有桌面坐标。用户确认纸牌临时摆放，仍使用默认桌角坐标。因此旧三牌校验拒绝映射，未形成有效轨迹。未把截图中无有效轨迹算作通过的实拍结果。

按用户选择增加免测量像素模式并设为默认：ID 4 单独可见就能输出像素位置和画面朝向，不依赖桌面参照位置。API 检查包含没有 layout 的像素请求、只有 ID 4、目标丢失、像素与毫米单位隔离；物品识别保持可用且不输出物理桌面区域。浏览器处理生成录像后实际导出 303 行／30 列，X 约 532.7–753.2 px，全部毫米列为空。原 27 列为此前界面版本，不是当前导出格式。

同一临时摆牌生成图：使用错误桌角坐标被拒绝并显示具体原因；填写正确坐标可恢复毫米跟踪，26 个位置检查通过。浏览器实际核对三牌错误提示（该生成图最大拟合差约 75.7 mm）、标定刷新后恢复及模式切换。所有生成场景均标 SYNTHETIC。用户实际 iPhone 接入后还需自行刷新确认，未验收真实桌面尺寸精度或整机路线。

## 四角自动坐标、未知障碍和边界／接近反馈

四角自动填写：在实际界面修改长深为 1000×450 mm、距边 50 mm，得到 0(50,50)、1(950,50)、2(950,400)、3(50,400)；切手动后改长深保留已填写值。计算用于预定摆放，不声称自动测量临时纸牌。

新 monitoring.py 与接口使用生成空桌／任意形状物体验证：未知变化不依赖模型类别，框外物体不计，定位码不计；近边／触边／越界／目标丢失分别返回不同状态。障碍接近用码四边到物品框的像素距离：测试近障约 20 px、重叠 0 px。未知变化置信度为空，不编造分类分数。

浏览器实际点击四角、记录空桌参考，暂停录像拖进度后看到未知变化、靠近黄提示、框重叠红提示、越界红提示及丢失的无法判断提示。实际导出 10 行／37 列 CSV，状态和 JSON 可解析，像素模式毫米列全空；记录 tmp/aruco_monitoring_20261123/browser-verification.json。

未以真实手机空桌及实物障碍验收，未证明可识别所有障碍。轮廓/矩形框、阴影与高物体投影都会影响判断，不把候选区域或图像重叠当成物理安全保障。
