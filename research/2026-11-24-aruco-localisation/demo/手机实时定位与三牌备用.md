# iPhone 实时定位演示

这版支持 Mac 接收 iPhone 摄像头画面、五块牌坐标表、ID 4 位置与朝向跟踪、视频录制和 CSV。手机到电脑用 Apple 连续互通相机，不需要在手机上访问 127.0.0.1，也不需要把网页开放到局域网。

## 接入手机

1. iPhone XR 或更新机型、iOS 16 或更新；Mac 使用 macOS Ventura 13 或更新。两端登录同一个开启双重认证的 Apple 账户。
2. 打开两端无线局域网、蓝牙。iPhone 设置 → 通用 → 隔空播放与连续互通，开启连续互通相机。
3. 用手机支架固定 iPhone，横向、后置镜头朝桌面、锁屏。USB 连接也可用，连接后在 iPhone 上信任 Mac。
4. Mac 打开定位台，点“开启摄像头”并允许权限；点“刷新列表”，在摄像头列表中选择 iPhone。选择后自动切换输入，原来的录像、轨迹和统计重新开始。
5. 若浏览器列表没有 iPhone，先检查连续互通设置、连接及两端系统权限；可在 Mac 的 FaceTime 中检查是否能选择这台 iPhone，随后退出 FaceTime 再测试定位台。不要让其他程序占用镜头。

关闭人物居中、人像和桌上视角等视频效果，避免动态裁切、虚化或软件变形影响定位。使用固定的常规后置摄像头画面，测试过程中不变焦、不移动支架。手机列表接入路径已实现，实际手机尚未连接并验收，不能将生成样本或网上照片记作手机实拍。

来源：[Apple 连续互通相机说明与系统要求](https://support.apple.com/zh-cn/102546)。

## 支架与坐标

模拟高度量“镜头中心到桌面”的垂直距离，不能用手机顶部或机械臂总高代替。RigArm 未到货，先记录支架设置的实测高度、拍摄角度、画面分辨率和远近端标签的可读性。相同高度不保证 iPhone 与 RigArm 镜头有相同视野。

桌面按 1500 × 650 mm。坐标原点在靠操作者的左近角，X 向右、Y 向远侧。ID 0 近左、ID 1 近右、ID 2 远右、ID 3 远左。默认四张牌的中心分别为 (50,50)、(1450,50)、(1450,600)、(50,600)，必须用尺测后在“桌面标定”中改为实值。

五牌坐标表同时显示图像中心 px 和桌面 X/Y mm。ID 0–3 的桌面坐标来自用户输入的参照点，不是四个独立的精度测量结果；ID 4 为图像计算位置，移动时持续变化。图像中心不需要建立桌面映射也可显示。丢失的牌、重复牌和没有有效映射时，不沿用上帧桌面坐标。

初轮五张纸牌应平放、近似同高。把 ID 4 放到机器人车顶后会产生高度视差，仍需标定并修正，不能沿用纸牌误差当作小车定位误差。

## 摄像头在 ID 3 附近

ID 3 可能落到视野外或拍摄角度过斜。第一选择是把它往内移到可见位置，然后填写新的实测码心坐标。参照牌不必正好位于物理桌角，但要分散、可见，四点按 ID 0、1、2、3 环绕桌面且保持凸形排列。

如果只剩 ID 0、1、2，或者任意另外三张参照牌，可在“桌面标定”打开“三张参照牌备用定位”：

- 实测并填入参照码黑框边长，默认 60 mm，**不包括白边**。
- 所有 ID 0–3 的图案上边统一朝桌子远侧，不能各自任意旋转。剪裁前可在白边外标记朝向。
- 程序用三张码的 12 个角点拟合平面单应变换，并检查拟合残差；不是只用三个中心强行做透视变换。
- 任意三张参照可见时启用备用；四张齐全时优先使用四中心模式；少于三张时停止输出桌面坐标。尺寸或朝向不符、角点不一致时会拒绝备用定位。
- 备用默认关闭，避免旧摆放方式没有统一朝向时误输出。可在标定窗口勾选后启用。标定应用后会保存在当前浏览器，刷新后恢复；其他电脑的默认配置仍来自 layout.json。
- 三牌覆盖的区域以外属于外推，角点误差更易放大。应实测远近端和缺牌附近的精度；通过生成图并不证明实际角度下可用。

## 第一轮实测

先暂时关闭“识别桌面物品”获得更高的定位处理频率，跑通手机与五牌后再开启物品识别。两功能可以同时运行，处理速度以页面显示的单帧耗时为准。

先录 20 秒静止 ID 4，再手动沿直尺移动并旋转，遮住 ID 3 测备用模式，最后遮住第二张参照确认坐标停止。导出的 CSV 含每张牌的可见状态及 X/Y、映射模式、图像坐标 JSON，以及物品类别/置信度/框。记录实测位置误差、丢失与恢复；不要把拟合残差当成真实桌面定位误差。
