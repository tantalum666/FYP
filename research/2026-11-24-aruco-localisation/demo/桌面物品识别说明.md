# 桌面物品识别

新增：空桌参考可以检测未知物品变化，并与 ID 4 越界／靠近提示联动，见《桌面范围与障碍提示说明.md》。下文 17 类指可命名的模型类别，不限制新增的变化检测。

网页可开启本机目标检测，支持实时摄像头、本地图片及录像。检测水杯、水瓶、笔记本电脑、显示器、键盘、鼠标、手机、书本、碗、花瓶、盆栽及部分餐具等 17 类物品。图像上显示中文类别、置信度及橙色识别框，右侧显示物品列表；默认阈值 40%，可在页面调整。

使用随包提供的 OpenCV Zoo YOLOX-S ONNX 模型，OpenCV DNN CPU 推理。模型在本机运行，不上传图像至云端，不使用 API 密钥或付费服务。网页功能由 app.py 提供；原 aruco_demo.py CLI 继续仅提供定位与原有记录。

四张参照牌齐全，或已明确开启并满足三牌角点模式时，物品框投影至当前桌面坐标图。没有有效映射仍能识别类别和图像框，但不显示桌面区域。即使 ID 4 暂时不可见，只要参照映射有效，物品仍可投影。

**地图橙色区是二维识别框的桌面平面投影估计，不是物体真实接地轮廓。** 高杯、打开的电脑屏幕和倾斜拍摄会产生高度偏差。还没有接入小车路线规划、车体半径膨胀或实车防撞/防跌落控制，不能据此声称自动避障已验收。

通用模型有漏检和误检。透明/反光杯、关闭的笔记本、很小或遮挡的物品可能识别不到；不支持类别的杂物也可能漏掉。“未检出”不代表前方无障碍，类别识别率和实际物体占地精度需分开测试。

录制视频包含识别框、桌面图和物品摘要；网页导出 CSV 增加 obstacle_status、obstacle_count、obstacles_json，JSON 含每件物品的类别、置信度、图像框和有条件的桌面区域。CSV 正确转义带逗号的 JSON。
