# 桌面范围、未知物品与接近提示

当前在同一个定位台中提供四项功能：四角码坐标自动计算、可见桌面范围设置、空桌参考变化检测，以及 ID 4 贴边／越界／靠近障碍物的视觉提示。默认仍是免测量像素模式，后续可切回毫米标定。

## 改长宽后自动填写码中心

打开“桌面标定”，参照牌布局选择“四角自动计算”，填写桌面长、深及“码中心距桌边”。四个码中心为：

| 牌 | X | Y |
| --- | --- | --- |
| ID 0 近左 | 距边距离 | 距边距离 |
| ID 1 近右 | 长－距边距离 | 距边距离 |
| ID 2 远右 | 长－距边距离 | 深－距边距离 |
| ID 3 远左 | 距边距离 | 深－距边距离 |

例如长 1000、深 450、距边 50 mm 时，自动得到 (50,50)、(950,50)、(950,400)、(50,400)。每次修改长深或距边距离都会同步更新。

这是预定的四角摆放坐标，不会自动测量纸牌实际位置。按计算值摆放黑框中心，或选择“手动填写实测坐标”。手动模式改长深不会覆盖输入的码心坐标。长、深必须大于距边距离的两倍，避免退化成一条线。免测量像素模式不依赖这些毫米坐标。

## 实际手机测试顺序

1. 固定手机及焦段，打开实时画面。
2. 点“标出桌面范围”，在画面里沿边缘顺序点击四个角，可顺时针或逆时针，不能交叉。蓝线表示设定范围。
3. 清空待检测的物品，定位牌可以保留，点击“记录空桌面”。
4. 再放入物品，移动 ID 4，观察画面框和上方提醒。

毫米模式如果已有有效桌面映射，也可自动使用投影出的桌面边界；像素模式需要手动圈选。圈出的若只是可见的一部分桌面，它代表演示区域，不能用于确认画面外的真实桌边。移动手机、变焦、画面分辨率改变或换输入后，重新圈范围并录参考。刷新页面不会保留旧画面的空桌参考。

## 未知物品检测

“识别桌面物品”继续给支持类别显示名称和模型置信度。“检测未知物品”独立对比当前画面与空桌参考，在设定区域内发现变化块，标为“未知障碍／疑似变化”；不要求物品属于水杯、电脑等模型类别。关闭类别识别后，未知变化检测仍可工作。

定位码本身及其白边附近会被排除。已由类别模型覆盖的变化区尽量合并，避免重复计数。参考画面中已有的东西会成为背景；要监测它们，录参考时先移走。未知变化没有模型分类置信度，界面不会给它编造百分比。置信度滑块仅调整类别模型，不调整空桌变化检测。

检测的是视觉候选区域，区域数不保证等于物体数，不能保证所有障碍都能识别。透明、低对比、细小物体可能漏检；阴影、反光、曝光变化或手机移动可能误报。画面变化很大时另提示检查手机和光线，必要时重录参考。

## ID 4 提示

| 状态 | 反馈 |
| --- | --- |
| 码面在设定范围内 | 绿色范围提示 |
| 码面接近设定边界 | 黄色贴边提示 |
| 码面部分越过边界 | 红色触边提示 |
| 码中心已在边界外 | 红色越界提示 |
| 接近障碍识别框 | 黄色提示，显示对应候选与像素距离 |
| 与障碍识别框重叠 | 红色重叠提示，标出可能接触 |
| ID 4 丢失或重复 | 提示无法判断位置／距离，不将丢失当成已离桌 |

接近距离按 ID 4 码面到障碍矩形框边缘计算，单位为画面 px；不是中心点之间的距离，也不是实际厘米。提示范围随画面分辨率调整。框重叠仅表示图像上的重叠，不能确认三维实体已经碰撞。实际小车外壳大于标签，后续还要结合车身包络、标定和车上感知验证；此版只提供显示和记录，未连接自动停车或绕障控制。

## 记录与复验

CSV 当前为 37 列，原像素/毫米列区分保留，新增 edge_status、edge_distance_px、generic_status、generic_obstacle_count、proximity_status、nearest_distance_px、proximity_threshold_px。像素模式仍不填入毫米坐标。

同目录“桌面监测生成测试样本.mp4”是标明 SYNTHETIC 的 160 秒录像，可以导入、暂停在最初空桌画面、圈四角并记录参考，然后拖动进度查看各阶段：0–20 秒空桌，20–40 秒远离物体，40–60 秒靠近，60–80 秒框重叠，80–100 秒贴边，100–120 秒触边，120–140 秒越界，140–160 秒目标丢失。暂停后拖进度也会重新分析选中的帧。

生成场景的函数、API 及浏览器流程已核对。浏览器真实点击四角、记录空桌并看到未知变化、靠近、重叠、越界和丢失提示；导出 10 行／37 列，包括上述状态，毫米列为空。四角自动计算及手动保留坐标也已在界面核对。尚未验收用户真实手机光照下的物品识别率、物理距离或整机防撞／防跌落性能。
