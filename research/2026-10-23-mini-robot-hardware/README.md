## 已完成的工作及证据边界

1. 收敛整机外观与上述硬件约束，重点由概念图转为Mini硬件可行性核验。
2. 研究市售桌面吸尘器改装、单电池分电、独立风机启停和无线充电。拆解视频能见两针电池/风机插接，但未确认针距、极性、额定电流，亦不能证明与最终购买SKU相同。
3. 曾制作12页A3内部接线采购前评审V3和后续单电池简图。它们是历史候选，**不能作为本版成品控制板方向的最终接线图**。V3双电池/双Qi/按键舵机等前提已被后续要求取代；新GPIO和完整线束未定。
4. 核对真实成品控制板、传感器、接头与行走件资料，形成当前9页目录。文档已逐页渲染检查；页数、图片、链接、包装数量及行走件算术已检查。这些仅是文档检查，不是硬件合格证据。
5. 发现并明确保留关键缺口：SH六针线不直插主控、部分反射传感器电压资料冲突、原风机与电池未知、Qi净充电和自动对准未验证。

## 当前候选与费用说明

控制方向为 **Cytron ROBO-ESP32 + MAKER-ESP32**，底板有双轮驱动及Grove接口；其集成充电、供电总载流、风机分电和保护覆盖仍须核验。**MAKER-DRIVE仅为风机独立驱动候选，不是还要额外购买的双轮驱动。**

恢复的行走参考组为 Pololu 5113马达2只、1087轮对1包、989支架对1包、951万向球1套、5543线2条，原币小计 **US$76.89**。以预算假设1USD=7.8HKD约为HK$600；不是实时汇率、不含转接链/运税，也不是整机总价或最低价方案。

**未锁定项包括：**吸尘总成、受保护电池、唯一充电/电源路径、Qi收发链、完整免焊线束、碰撞装置、部分检测与保护、底盘低位吸口、回座导向和主机电源。

## 相机路线的已确认条件

清扫时允许luwu rig arm固定在俯视观察位；Mini顶盖可以做彩色点或不对称标记，桌面不贴明显定位标签。整桌清扫是目标，实际桌面尺寸和覆盖范围未定。

2026-10-22的厂家源码核对仅发现快照/本机预览路径，相机配置为240×240；**未证明Pi能稳定连续取流**。参考仓库[LuwuDynamics/rig_omni](https://github.com/LuwuDynamics/rig_omni)，核对commit `c2b42cd73ef65f5cd2a158d6949f0273869454dc`。不能据此删除本地四角防跌落、失联停车或末端回座校准，也不能用它取代项目已有固定机位坐姿相机的要求。
