| 网页框架 | 顶部连接状态／助理／提醒改为正常布局行，避免绝对定位在不同页面上错位；主要页面统一边距和表单排版 |

| 记忆 | 正确的页面容器、全宽输入和事实列表；更正入口明确，删除先出现确认／保留操作；加载与真实空状态分开，删除文案只承诺未来请求不再包含该事实 |
| 风格 | 默认显示当前已保存风格概述，按需展开指令编辑器；保留未保存提示、离开保护、版本冲突及恢复语义 |
| 日程 | 首屏保留标题、全天、开始／结束和时区；分类、提醒、隐私等收进详情，但收起时显示当前重要值。保存／取消固定在表单外部操作栏，长表单滚动时仍可访问 |
| 日历 | 日／周／月视图适配实际剩余高度，避免新增顶部栏和助理后产生整页额外滚动；周视图在内容较窄时保留内部横向滚动。修正中文日／周标题及日期按钮的读法 |
| 记录 | 筛选按需展开，可清除；提供加载、无匹配、无记录和错误状态；记录名称使用正常用户文案，导出入口保持可见 |
| 事务 | 关闭跟进时不再展示实际无效的延后／暂停操作；明确通过编辑开启跟进。事务标题出现在专门讨论的助理中 |

## 保留的行为

所有修改仍走原API、拥有者权限、操作ID、版本校验及独立读回。未保存输入不能被页面导航或关闭静默丢弃。侧栏助理与模态编辑是不同层级；只有模态界面阻止背景操作，不能通过布局调整扩大权限。

没有改后端、原人物资产、模型选择、Google授权、硬件驱动或学校文稿；无新增前端依赖。Qwen Omni是现有已测基线，其他模型仍待比较。测试运行中语音／文字提供商均未配置，电脑执行器关闭，没有真实音视频、机械动作或模型费用。

- 前端测试 **59/59通过**，包括新增的三项侧栏位置／召回／原悬浮偏好保护检查。

- 实际浏览器检查1280×720、1440×1000桌面、900×720紧凑窗口及390×844中文表单；1440布局无整页横向／额外纵向溢出，人物与主区／助理区没有默认遮挡。
- 实际操作包括记忆保存／更正／取消删除，风格离开保护／保存，日程折叠字段／取消保护／保存，助理本地查询、主页面切换保留对话、事务创建／讨论、记录筛选／清除、角色悬浮／回侧栏。
