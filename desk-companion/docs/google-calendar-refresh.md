# Refreshing imported Google Calendar events

In **Calendar files → Google Calendar**, choose the dates of the local copies and select **Refresh imported events**. Review the changes and confirm or discard them. The last confirmed refresh shows the dates and counts. A refresh checks up to 50 imported entries overlapping a range of up to 31 days, with an exclusive end date. The separate **Preview date range** action can import new entries.

Each confirmed import associates its local event, last imported version and Google event or occurrence ID with the current OAuth connection. Refresh reads each associated ID from the primary calendar, so it can find a meeting that moved beyond the selected dates. A cancelled event or an explicit `410 deleted` response offers the local copy for removal. A `404 notFound` can also mean lost access, so the review keeps that copy as unavailable. Local edits, occurrence exceptions and unsupported Google changes stay on the desk. Editing a copy or confirming a newer review of it invalidates its pending refresh. Confirming uses the existing local importer and writes only to the desk.

Earlier imports stored only a hash of the Google ID. When the desk has a single recorded Calendar grant and has never disconnected it, refresh can match those hashes from an ID-only list in the selected dates. It retrieves details only for matching IDs. An old event that moved or disappeared before its ID could be matched stays unresolved. Reauthorization creates a new grant version. Copies without verifiable provenance stay local, and a new date-range import can create separate copies for the current grant.

The importer expands occurrences with time bounds and start-time ordering. Google restricts these parameters with a collection sync token. Refresh uses bounded reads and stores no sync token. Range lists allow up to ten pages and 500 items. A 410 during pagination restarts the same range once from the first page. A failed read publishes no partial preview. Retrying the original operation key can recover a pending review for 15 minutes or the receipt for a confirmation or discard.
