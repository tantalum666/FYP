# 拥有者记忆

2026-10-14，Group 2。这是 Desk Companion 的长期事实，不是聊天全文，也不是电脑作业。

英文：the owner saves, corrects, and deletes facts. The model may read active facts and prepare a draft. A draft does not write. Deleted facts are omitted from later model context. A paired display cannot open this list.

## 行为

- 拥有者在「记忆」页直接保存、更正或忘掉。页面标题是「我了解的关于你的事」，每条显示来源、更正前的文字和到期时间。每次写入带版本；版本不符返回 `VERSION_CONFLICT`。
- 折叠空白、忽略大小写和句末标点后文字相同的事实只保留一条。再次保存返回已有事实，`duplicate: true`，不占新名额。把一条改成另一条已有事实的文字返回 `MEMORY_DUPLICATE`。
- 更正会留下上一版正文，模型上下文只看到新正文。到期时间由拥有者设置；到期后事实仍在「已到期」里，可忘掉，但 `for_model` 不再包含它。
- 已经分别保存的相同文字会出现在核对建议里。拥有者发起的核对走既有助理草稿：确认后保留最新一条并停用其余，取消不写库。草稿过期或版本变化返回 `MEMORY_REVIEW_STALE`。
- 本地规则无需模型密钥：`记住：…`／`Remember: …`，以及整句的姓名或偏好（`My name is …`／`我叫…`／`I prefer …`／`我更喜欢…`）只准备草稿。问句、任务和约会不提取。`忘掉：…`／`Forget: …` 仅在文字与某一条活动事实完全相同时准备删除草稿。确认前不写库。
- 可选的托管提取必须同时设置 `DESK_MEMORY_EXTRACT=1` 和 `DESK_MEMORY_EXTRACT_CAP`（1–20，按 UTC 日计算，含失败）。它只走现有文字适配器。模型给出的事实必须原样出现在该条消息里，否则丢弃。默认上限是 0，不会调用。确认仍由拥有者完成。
- 模型工具是 `memory_query`、`memory_save_draft`、`memory_replace_draft`、`memory_delete_draft`。没有确认工具，也没有合并工具。确认仍走既有助理草稿接口。
- 发给托管模型的上下文由 `desk/context.py` 的 `pack_conversation` 组装，最多 40 条仍有效的事实。删除、到期和已停用的正文不再出现。密钥、相机帧和笔记文件内容不在这个包里。
- 活动事实最多 200 条，每条折叠空白后不超过 500 字。达到上限是 `MEMORY_LIMIT`，不会静默丢掉旧事实。与已有事实重复时不占用新名额。
- 配对终端访问 `/api/memory` 得到 403，助理草稿列表、确认接口和文字／语音工具也执行相同的拥有者边界。配对文字请求不打包事实，回复缓存绑定调用权限；语音只向拥有者或已启用的本地语音工作进程开放记忆工具。常亮屏不展示这些事实。

## 与电脑作业的关系

受限笔记作业和拥有者指定的一个文件夹共用同一套作业：批准全文，执行器只新建 `<作业ID>.txt`，独立读回字节数和 SHA-256，取消不会假装回滚。见 [computer-jobs.md](computer-jobs.md)。记忆不代替这项作业，也不新开第二套任务系统。

## 现有能力与剩余验证

1. 本文件所述的记忆、草稿和上下文打包。已实现，并用模拟／本地规则测试，没有付费模型。
2. 已在 main 上的专用笔记作业：批准、独立读回、取消。默认关闭。
3. 拥有者指定一个真实文件夹，沿现有作业契约保存、独立读回和取消。已实现，见 [computer-jobs.md](computer-jobs.md)。模型不能提交路径。
4. 文字和语音共用一份可编辑人格文本。已实现，见 [persona.py](../backend/desk/persona.py)。模型不能改这段文字。工具协议仍由程序附加，避免删掉确认限制。
5. 关闭单项跟进后，已经排队的可选文字建议不再发给模型，事务本身保留。已实现。
6. 安静时段推迟新的跟进，同一次检查最多放出 3 条。推迟保存在库里，重启和改保存的时段之后仍按当前偏好执行。已实现。
7. 文字供应商是可替换适配器，用模拟响应测试。已实现。有花费上限之前不要开通模型账号。
8. 真实模型验证：有花费上限之后，才用同一套工具比较托管供应商。供应商仍未锁定。
9. 不在这一步：合并 PR #4／#5、通用浏览器、收件箱、自称姿态准确率或减损效果。

人格重置会保存新的递增版本，旧编辑不能因恢复默认而重新生效；已有配置追加迁移保留正文。保存失败／冲突保留本地草稿，只有明确选择加载当前文本才放弃。记忆、人格及作业尚未包含在现有业务JSON备份中；删除事实不保证从已有提供商会话或历史操作记录中擦除。
