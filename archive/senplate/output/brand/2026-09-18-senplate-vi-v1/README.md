# Senplate VI Kit V1

2026-09-18。以已选V7纯碗为主标。用户已澄清本次需要整套VI视觉识别，不是原生.ai文件。

## 先看什么

- `02_Guidelines/Senplate_VI_Guidelines_v1.pdf`：11页规范。
- `02_Guidelines/Senplate_Vector_Assets_Master_v1.pdf`：4页矢量资产总表。
- `02_Guidelines/vi-overview.png`：快速总览。

## 文件目录

- `01_Logos/SVG`／`01_Logos/PNG`：独立图形、独立字标、横向、上下组合，各有绿色／黑色／反白，共12个版本；PNG为透明底。
- `03_Tokens`：颜色、字体和间距的JSON／CSS设计令牌。
- `04_Applications`：App图标基础稿及未裁切前景／背景、演示封面、菜单立牌、设备标贴，提供SVG／PNG。
- `05_Fonts_and_Licences`：当前三种原始字体、许可与来源校验；Inter为历史字体许可核查副本。
- `06_Source`：可编辑字标SVG、Figma源稿位置和使用规则。

## 使用提示

缩放与加工选SVG，插入文档选PNG。反白PNG是透明底白图，放在白底上可能不易看见。生产Logo和应用SVG已经转轮廓，不依赖安装字体；可编辑文字SVG例外，先安装Manrope。

Manrope与Noto Sans TC／SC可免费商用，随包分发字体时保留许可；详情见05目录。主标志是用户已选版本，辅助色、使用规则及应用模板为本次制定的VI V1。QR需替换，App图标仍需平台接入；本包不代表软件或实物已验收。
