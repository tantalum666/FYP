# Senplate Brand Assets V1

2026-09-17。基于用户明确选定的“A方案·细化版”。原参考板上方大号深绿 Logo 为统一依据。

## 日常使用

| 文件 | 用途 |
|---|---|
| `senplate-logo-green.svg` | 默认横向 Logo，可缩放路径 |
| `senplate-logo-black.svg`、`senplate-logo-white.svg` | 同一轮廓的纯黑、反白版本 |
| `senplate-logo-*.png` | 1600px宽、透明底，便于文档／演示使用 |
| `senplate-mark-*.svg`、`senplate-mark-*.png` | 独立符号；PNG为512px宽 |
| `senplate-wordmark-green.svg` | 原图字标的轮廓路径，不是可编辑字体文本 |
| `app-icon-*-1024.png` | 1024×1024完整方形图标源图；默认forest |
| `senplate-mark-24.png`、`32.png`、`64.png` | 小尺寸检查样本；24px盘沿偏细，建议至少32px、优先48px以上 |
| `brand-preview.png` | 主色、单色及图标的组合预览 |
| `source-selected-a.png` | 用户选中的原始参考板，原始字节保留 |
| `manifest.json` | 来源、导出节点、尺寸、哈希与状态 |

## 约定

深绿 `#163F35`、米白 `#F3F1E7`、黑 `#000000`、白 `#FFFFFF`。图形和字标等比缩放，不改变餐盘、份量形状或圆点的相对关系。主 Logo 图文间距已包含在 SVG 中。

SVG是对原图上方主色版进行轮廓提取、边缘清理后的平面版本；PNG由Figma原生导出。所有配色共用同一轮廓。原图字体名称未确认，未替换字体，不把历史Manrope稿件混入此包。

原图说明文字和口号留作参考；没有正式中文品牌名。已选择本视觉，不等于完成新图形的商标检索或注册。文件不含组员身份资料，也不含应用实现或发布结果。
