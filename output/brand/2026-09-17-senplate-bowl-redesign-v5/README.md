# Senplate V5 · 实体碗候选

2026-09-17。用户明确否决V4的碗识别度并要求重新设计，本目录是新概念，尚未选定。

- `bowl-01-concept.png`：当前米白底展示版，1774×887、不透明RGB；有完整碗口、实体碗身和底脚，字标为Senplate。
- `bowl-01-generated.png`：第一次生成的透明原稿，保留追溯。
- `manifest.json`：生成方式、来源、尺寸、哈希及能力边界。

两张均来自内置ImageGen；第二张以第一张为目标作浅底与平面化编辑，复制原生字节保存。没有Python图像修改或CLI/API替代。

本稿仍有轻微生成纹理及口沿／底脚细线；它是用于判断造型的栅格效果图，不是已经完成的纯色矢量、最终字体、黄金比例检验或App图标素材。造型通过用户评价后再矢量清理和做小尺寸检查。阶梯形留白表达份量／水平参照的设计意图，不是已验证的用户理解结果。

首字母大写是本候选的设计建议，与iOS名称Senplate一致，尚未作为新Logo写法获用户确认。旧A／V1–V4保留历史，当前不再按环形盘沿路线继续修补。
