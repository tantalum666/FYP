## Calendar and authorization

- One local snapshot uses the calendar’s canonical recurrence expansion, moved/cancelled occurrences, all-day semantics and busy/completed flags. The comparison covers the trip from first departure to last arrival, including connections. An event that ends at departure or starts at arrival is adjacent. Ground transfer and check-in time are outside the comparison.
- Explicit UTC offsets identify instants. Naive source times use the relevant airport’s IANA zone. Unknown zones, ambiguous or nonexistent DST wall times and invalid segment chronology cannot establish a clear interval. Some test fares use an elapsed duration that differs from the two airport-local endpoints. If only one possible end overlaps a meeting, the result is unverified. A verified fit must clear both ends. The original timetable is displayed unchanged.
- The offline map contains 7,950 unambiguous IATA codes in 357 timezones, derived from the pinned MIT-licensed airportsdata 20261103 wheel. The generator verifies the wheel’s SHA-256, writes the compact index and preserves the upstream license. [Dataset](https://pypi.org/project/airportsdata/20261103/) · [Rebuild script](../../../desk-companion/scripts/prepare_airport_timezones.py) · [License](../../../desk-companion/licenses/airportsdata-LICENSE.txt).
- A checked option carries the owner-selected route, flight and budget to the existing official Function. The local review verifies the returned itinerary even if a model omits or changes an optional argument. The supplier search contained only airports, date, passenger count and currency. No calendar entry, title or busy interval was sent to LetsFG. The protocol test also checked the synthetic private event text against Session creation, continuation and function outputs. [Official OpenAI Functions](https://developers.openai.com/api/docs/guides/agents-api/tools/functions).
- Financial admission checks the original login and current calendar inside the same SQLite write transaction that records approval. Network submission happens after commit. A changed calendar can block a first submission or acceptance of a supplier increase; declining remains possible. Another-flight lookup is restricted to unsubmitted reviews in the original login and chat. It reuses the original filters, excludes the previous service, then returns a new unapproved review.

## First failure, usage and release evidence

The original live run used the correct Function, but the previous five-second lookup timed out and its retry failed at connection. That turn produced no order or approval. A separate read of the same anonymous route returned 50 offers in 6.73 seconds. The repaired adapter allocates a shared 24-second window to at most two search attempts and the quote Function has a 28-second execution budget. Payment, booking, stop and reprice-answer transport policies remain the original ones. The repaired native request and the subsequent fare selection both returned live supplier offers. The controlled Web replay also covered loss of the model’s calendar flag and an intervening calendar edit. [LetsFG search documentation](https://letsfg.co/developers/docs/api-search/index.html) · [Sandbox](https://letsfg.co/developers/docs/api-sandbox/index.html).
