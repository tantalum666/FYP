# Group 2 · Weather at a named airport or other fixed site

The geocoder returned the public feature for Narita International Airport, but the existing field check retained only populated-place codes. The resolver now accepts an exact localized name for documented fixed-point feature types such as airports, railway stations, observatories, mountains and peaks. Simplified and Traditional comparisons use the existing language dictionaries. Country and region qualifiers still apply. Multiple exact sites, or a city and site with the same name, require clarification. Unverified airport-code aliases and fuzzy feature matches do not select a forecast point. Unresolved names offer a country, region or coordinates. [Geocoder matching contract](https://open-meteo.com/en/docs/geocoding-api) · [GeoNames feature definitions](https://www.geonames.org/export/codes.html).

On 23 November at 15:21 UTC, ordinary Chinese and English messages independently resolved 成田国际机场 and Narita International Airport to the same Japanese AIRP, GeoNames ID 6300307. The geocoder supplied 35.76472, 140.38638. Both forecasts used the airport's rounded public coordinates 35.76, 140.39 and the Asia/Tokyo timezone. At 00:15 JST on 24 November, Open-Meteo estimated 7.9°C. The local day had a 7.9–18.6°C forecast, 100% peak hourly precipitation probability and 14.5 mm expected. The English question about tomorrow correctly returned 25 November, 5.3–12.2°C, 12% peak hourly probability and 0 mm forecast. [Authenticated message and provider receipts](receipts.json).

A separate real Mount Fuji lookup returned only the American Mount Fuji Airport. The normal reply requested a region or coordinates. It made zero forecast requests for that fuzzy match. The focused tests also cover a shorter Chinese name, same-name sites, a city sharing a site's name, an unverified IATA-like alias, a broad country, a range with a similarly named village and a supplied exact peak name.
