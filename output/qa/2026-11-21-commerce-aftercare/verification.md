## Implementation and recovery

The ordinary OpenAI Session keeps its existing quote Functions. The owner requests cancellation in chat or through the matching card. Local code binds the request to the authenticated owner, original conversation, order and applicable review. A generic request with multiple matching orders asks the owner to choose. An eligibility question reads the existing order. The model receives presentation data and has no new payment or refund Function. [Official OpenAI Functions](https://developers.openai.com/api/docs/guides/agents-api/tools/functions).

The FYP Woo extension checks the original test guest order, gateway, total, currency and fulfilment eligibility. It records the buyer’s request and puts the order on hold before calling the installed WooCommerce refund gateway. Stock restoration uses the original line quantities. A retried request with a stored cancellation marker only reads the existing outcome. The client waits for the matching finalized Woo and Stripe amounts. Pending, failed, partial or mismatched evidence cannot produce a full-refund receipt. This is the cancellation policy of the FYP merchant sandbox. [WooCommerce refunds](https://woocommerce.com/document/woocommerce-refunds/) · [Stripe refunds](https://docs.stripe.com/refunds).

For flight stops Alice polls the original booking. She reports a release only after a terminal supplier read confirms it. A supplier handoff to a person, an uncertain acknowledgment and a stop received after payment have distinct outcomes. A completed purchase retains its verified PNR and captured amount when the provider confirms them. A post-ticket refund requires a separate seller fare-rule and refund path. The initial FR4315 no-match case produced no order and prompted a new implementation. Tested offers must still satisfy the requested date, route, party, direct-flight constraint, currency, carrier when specified, and price ceiling. [LetsFG sandbox booking and stop states](https://letsfg.co/developers/docs/api-sandbox/index.html#5-stop-a-booking).
