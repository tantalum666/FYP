# Group 2 单台 demo 统一供电采购与接线说明

更新：2026-09-15。状态：已核对公开规格的工程候选，尚未采购／上电。只覆盖一台Pi5、一个Gemini2、一个称重位置、7英寸Touch Display2和两条小功率USB灯。多餐位不在本期范围。本文细化并取代此前未指定模块的12V／24V通用候选；原采购XLSX／JSON和V1/V2建议书保留。

## 推荐组合

**12V／5A成品适配器＋亚博YB-MPP01-V1.0 Pi5电源板＋奥睿科ORICO-BT2U3-7AB独立供电USB3 Hub。**适配器参考明确型号为Mean Well GST60A12-P1J，中国官网列有该系列；可用经核对的同规格国内成品替换，不要求海外购买。

12V同时匹配Pi电源板和Hub。Pi支路给主机、屏幕、风扇和小功率采集；Hub支路给相机和两条5V灯。本组合中Hub自带12V到USB5V供电功能，省去另购灯用降压板。两块功能板不等于新增两台设备，最终均装在同一demo内。

主机仍是Pi5 8GB，Arduino不是供电的必要组件。这里的电源板只处理供电，不承担食物识别或模型训练。

来源：[明纬中国系列页](https://www.meanwell.com.cn/webapp/product/search.aspx?prod=GST60A)、[明纬中文数据表](https://www.meanwell.com/Upload/PDF/GST60A/GST60A-SPEC-CN.PDF)、[亚博官方产品](https://category.yahboom.net/products/power-board-pi5)、[奥睿科官方产品](https://orico.com.cn/index/product/detail/2290.html?mtpl=1)。亚博基本板套装国际页面本次显示US$9、有库存；这不是国内成交价。奥睿科不同历史资料存在2.4A说法，本方案采用本次中国官网图中的1.5A，不混用宣传版本。

亚博输入端有KF301-2P螺丝端子、XH2.54和DC5.5×2.5；输出端包括USB-C、5V插座和排针。本方案选**KF301输入＋USB-C输出**，其他输入输出不用。不要把适配器插入板上DC5V-OUT插座；输入DC5525与适配器DC5521也不是同一规格。

亚博板通过独立固定和USB-C线连接，不使用其刚性双Type-C转接板堆叠在Pi上；这样可保留Pi散热器、GPIO和屏幕安装空间。官方未公开该板完整电路，也不能由商品描述证明所有温度条件都能持续5A输出。

## 供电与数据连接

实线为供电，虚线为数据。市电只到外置成品适配器；底座内只有低压侧。

```mermaid
flowchart TD
  A[英规插座] --> B[12V 5A外置适配器]
  B --> C[DC5521入口／低压保险／总开关]
  C --> D[12V正负极分配]
  D --> E[亚博Pi5电源板]
  E -->|USB-C 5V 5A协议| P[Pi5]
  P --> S[Touch Display2／风扇／ADC]
  D --> H[ORICO Hub的12V输入]
  H --> K[Gemini2：供电及USB3数据]
  H --> L1[5V灯1]
  H --> L2[5V灯2]
  P -.USB3上游数据.-> H
```

这里只共用12V输入，不把Pi支路与Hub支路的5V输出直接并联。Hub外接供电是否向上游VBUS倒灌尚未核实，不能以同一个12V来源为由省略检查。

### 逐线接法

| 从哪里 | 到哪里 | 线与要求 |
|---|---|---|
| 墙面插座 | GST60A12的C14入口 | 正规BS1363英规插头→IEC C13成品线，约1.5m；不用自己接市电 |
| 适配器原装DC5521公头 | 设备DC5521母座／母头尾线 | 中心正极；母座及尾线额定至少12V5A，18AWG或更粗，固定防拉脱 |
| 入口正极 | 低压保险座→低压总开关→正极三位连接器 | 在12V正极上分配；保险及开关需有相应DC额定，不能只凭AC字样选 |
| 入口负极 | 单独的负极三位连接器 | 与正极使用不同连接器；三位连接器内部导通，不能把正负极插进同一只 |
| 正／负分配各一支 | 亚博KF301输入端的＋／－ | 18AWG短线，建议约0.2–0.3m；按板上丝印，不凭朝向记左右 |
| 亚博USB-C输出 | Pi5 USB-C电源口 | C公→C公，约0.5m，5A e-marker线，可标100W／240W；电源线可为USB2数据规格，但必须有正确CC协商线路 |
| 正／负分配另一支 | Hub的DC12V口 | 18AWG短尾线；**公头内径、插入长度及极性待对照Hub原装适配器确认，不先猜5521或5525** |
| Pi蓝色USB-A口 | Hub上游数据口 | 优先使用Hub原装USB3线；图中上游为USB3 Type-B形态、字段写A T B M，官网另有USB-A输入的矛盾，选套装并按实物核对，勿自行以A-A线连接 |
| Hub一个USB-A数据口 | Gemini2 USB-C | 沿用原C02：USB3 A公→C公、5Gbps、约1m；保留完整相机数据及电源 |
| Hub另两个USB-A口 | 两条5V灯 | 各用灯自带线，每条≤2.5W；不把它们插回Pi USB |
| Pi物理pin2／pin6 | Touch Display2电源线 | 原装线：5V／GND；不要把外部12V接屏幕或GPIO |
| Pi CAM/DISP | Touch Display2 DSI | 原装22针小口→15针排线，断电连接；不是HDMI或USB触摸线 |
| Pi专用FAN／3.3V接口 | Active Cooler／NAU7802 | 延续原接线；电源板不占用Pi40针GPIO用于自身数据通信 |

屏幕接线依据：[Touch Display2官方安装说明](https://www.raspberrypi.com/documentation/accessories/touch-display-2.html)。Pi供电依据：[官方USB Power Delivery白皮书](https://pip-assets.raspberrypi.com/categories/685-app-notes-guides-whitepapers/documents/RP-009856-WP-1-USB%20Power%20delivery%20on%20Raspberry%20Pi%205.pdf)。

Hub套装中的12V／2A小适配器可保留用于独立台架检查或备用；完成统一供电后不用它占第二个墙面插头。不要剪开原装适配器或相机线制作Y型供电线；Hub支路另购匹配低压尾线。

## 功率预算：只针对当前三个Hub外设

这些数值是预留和计算，不是设备实测功耗。Pi支路的25W是整板输出上限的预算，屏幕、风扇及采集都包含在内；持续负载要留温升余量，并用实物确认。

| 负载 | 设计额度 |
|---|---:|
| Pi5＋屏幕＋风扇＋小功率采集 | 25W，计在亚博板的共同输出额度内 |
| Gemini2 | 按5V×1.5A预留7.5W；不把平均功耗当作峰值保证 |
| 两条灯 | 合计最多5W |
| Hub控制及其他 | 2W工程预留，实际待测 |
| 负载侧合计 | 39.5W |
| 假设两支路转换效率均按80%估计 | 约49.4W，12V侧约4.12A |
| 60W适配器剩余额度 | 约10.6W，约17.7% |

Hub下游外设总电流预留为1.5＋0.5＋0.5＝2.5A。含2W控制预留，按80%效率算该支路约18.1W，低于其配套24W输入额度。**不预算剩下四个Hub口给手机充电、SSD或其他负载**；若增加外设必须重算。厂家单口1.5A与总输入24W都是限制，不能任意相乘扩展。

80%效率是工程假设，不是厂家保证。若实际启动电流、支路电压或温升不合格，要调整模块／线缆／负载，必要时提高适配器容量；只换大适配器不能突破亚博板5A或Hub单口／总功率限制。Gemini2的官方建议为DC5V且供电能力≥1.5A：[中文参数](https://www.orbbec.com.cn/index/Product/info.html?cate=38&id=51)。

Pi USB总电流仍受主板限制；本方案把相机和灯的主要电源需求放在独立Hub支路。Pi识别到5A供电后开放的外设预算，不等于USB口能任意输出5A。PD握手不成功时应排查板、线及固件，不用强制参数掩盖不匹配。

## 装配工作与开关机

- 适配器保持外置，底座安装低压入口、总开关、绝缘分配和模块。使用预接尾线、螺丝端子和拨杆连接器可以减少焊接；如果买裸插座／开关焊片，需要少量低压焊接及绝缘。
- Pi仍需通风和Active Cooler；电源板与Hub也保留散热。145×58×26mm的Hub、65×56mm电源板和线缆弯曲空间要纳入机盒，原200×150×80mm项目盒只是候选，未完成排布校核。
- 机架、屏幕、Hub和线束全部固定在静止结构，不牵拉浮动秤板；电源线与毫伏称重信号分开走线，检查开关灯是否影响称重读数。
- 亚博板开关控制自己的Pi支路，不能当作整个设备总开关。整机关机先让Pi完成软件关机，再切断12V总电源；不默认加入电池、UPS或定时开关功能。

## 接线前仍要核实的事项

1. **Hub DC公头及极性：**本次官方参数未披露内径、插入长度和极性。以原装适配器标识、尺寸测量和低压电压确认后制作PS07；不让“插得进去”代替规格匹配。
2. **Hub上游防倒灌：**官网没有提供相应电路证据。只给Hub供电、上游不接Pi时，通过合适USB测试转接板检查上游VBUS是否输出电源；发现异常不连接Pi，需进一步确认或换合适Hub。普通高阻电压读数本身不能量化危险电流，避免凭一个读数就认定设计合格。
3. **Pi PD协商和热负载：**核对Pi能够识别相应供电能力；选定线缆、屏幕及模型一起运行，无欠压／过热降频等异常。不得只凭电源板名称写成已通过。
4. **相机与Hub配合：**BC1.2标称不是Gemini2组合实测。检查USB3枚举、RGB-D持续采集、实际电流及启动；两灯同开时仍要通过。

## 待执行的台架检查顺序

先记录所有型号和线材、查短路与极性；以适配器的原装输出核对12V。单测亚博板输出，再接Pi和屏幕；单测Hub原装供电及上游行为，再接相机。两路都正常后接共同12V分配，加入灯和全部采集／后台／视觉服务。

正式记录冷启动重复试验、从最低到最高屏幕亮度、灯的开关、相机重新连接及至少覆盖计划demo时长的连续运行。保留各支路电压、电流、模块温升、Pi欠压／降频状态、相机掉线和称重稳定性。台架试验不主动短路或试探市电；没有电子负载或合适仪表时借用学校器材并限定结论，不能把“开得了机”当成全负载验证。

## M2 Pro Mac 怎么训练，Pi 5 8GB 用什么模型

Python／PyTorch 可通过 MPS 使用兼容 Mac 的 GPU。[官方 MPS 说明](https://docs.pytorch.org/docs/main/notes/mps.html) 用户已确认 M2／16GB，足以作为限定菜品、轻量视觉与小型融合层的合理训练起点；尚未运行训练，不能给出可靠的训练小时数。当前工作机只读检查到 macOS 26.5.2 和约 473GiB 可用磁盘，属于环境信息，不是模型性能验证。

建议参数起点是 224×224 分类输入、batch size 16；先训练新分类／融合层，再按验证情况微调部分主干。内存紧张时减到 8，显存／算子条件允许再比较其他批量。训练集不要整批常驻内存，逐批读取；初期不要求云GPU。更大的分割或视频模型另行评估。

Large 的原始预训练网络约 548 万参数、权重 21.1MB；Small 约 254 万参数、9.8MB。这里是公开网络大小，不是完整运行内存。8GB Pi 给相机缓冲、后台和图像处理留有容量空间，但其 CPU 不因内存从4GB增至8GB就变快。[Large 模型依据](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v3_large.html)

训练在 Mac 上做，导出后在 Pi 上使用 ONNX Runtime CPU 推理，保持类别映射和图像处理一致。先 RGB 基线，再把深度计算出的高度／表观体积／有效比例与 RGB 特征融合；不因为增加深度就默认训练大型三维网络。最终按独立烹饪批次的识别、拒识、人工确认负担及整机时延选择 Large 或 Small。

## 安装距离与供电必须一起考虑

以相机到被测平面0.45m、正对平面为几何示例，Gemini2在16:9 RGB视场86°×55°时约覆盖84×47cm；D435的RGB69°×42°约覆盖62×35cm。它们说明名义覆盖，不证明体积测量精度。相机到最高食物表面的距离才决定是否仍处于有效近距范围；高度变化、盘壁、蒸汽和深度空洞都要测。

参考机械结构可把镜头调到承载面上方约0.45–0.55m，目标为一只GN1/3浅盘或约24cm餐盘。先检验所有目标都在实际彩色／深度共同有效区域，再固定高度和设计外壳。不以平台面积直接代替可测食物面积。

Pi5官方27W电源具备5.1V/5A输出并自带1.2m线；选UK英规版本适配香港。普通“65W手机充电器”不一定提供Pi所需的5V/5A档位。Pi在合适5A电源下的USB外设电流预算约1.6A，并与风扇供电预算有关；低功率供电条件下会限制到600mA。[官方电源](https://www.raspberrypi.com/products/27w-power-supply/)、[USB供电说明](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html)

Gemini2厂商建议5V≥1.5A，平均功耗<2.5W不能当峰值保证。首轮用短USB3数据线直连，只给Pi的USB接必要设备；补光灯单独供电，系统使用microSD，避免额外USB SSD和灯占预算。若有掉线或电压问题，必须检查线与供电，必要时选经过数据口电流／带宽／不倒灌验证的独立供电USB3 Hub。不能只靠软件强制放宽电流限制来认定供电已解决。

### 只需插接的部分

Pi电源、相机USB、显示DSI和显示供电、官方风扇都可以用正确套装直接连接。NAU买焊好端子与排针的版本，可使用螺丝端子和短跳线。显示屏、Pi和ADC尽量靠近，避免为了外形先把I2C线拉长。

### 需要机械加工或少量焊接的部分

承载底板和浮动板要钻孔，称重梁两端通过刚性垫块分别安装，框架、相机和屏幕则固定在静止底座上。2020可让商家按长度切割；PCB、Pi和相机都不用自己改板或焊芯片。LED、电阻和按钮接头可能需要少量焊接，外壳需开接口孔、按钮孔和通风口。

**机械尺寸是样机设计建议，不是加工定稿。**普通直梁的75mm尺寸不等于厂家保证350×250mm平台的偏载精度。必须做中央和四角负载试验；若不达标，调整板结构或使用有相应平台规格的单点传感器及匹配测量电子模块，再固定最终孔位。只可在底板／安装板上钻孔，不改动称重梁的敏感结构。

过载限位正常时不能接触浮动板；线束、机架和外壳也不能替食物承担一部分重量。隔热垫和热食会影响长期读数，必须在实际温度条件下验证。首版不是可放在炉火或沸水保温槽上的工业食品设备。

### 不建议第一轮就做的改动

首轮不开发定制PCB，不拆相机换镜头，不在镜头前自行加普通玻璃罩，不接市电加热控制，不先买AI加速卡和温度阵列。已有UNO R4 WiFi保留作调试备选，不需要再买一块Arduino。

## 到货后的检查顺序

1. 核对每个型号、套装线材、序列信息和退换条件；确认相机能读取原始RGB与depth。
2. 在Mac上先用厂家Viewer读取；再在Pi的实际系统上验证相机SDK和USB3连接。记录软件／固件版本。
3. 安装称重梁和临时刚性底座，用砝码验证多点、重复、偏载、升降载及稳定时间。没有机械结构时，只能验证ADC连通，不能宣布称重准确。
4. 相机拍平面和已知尺寸物，检查视野、RGB-D对齐、有效深度比例、距离误差和反光／蒸汽条件。不要把2m官方参数线性换算成0.4m食物精度。
5. 让相机、称重、模型和界面一起运行完整计划餐期，记录掉线、延迟、漂移和温度；硬件稳定后再扩大菜品数据。
6. 用独立烹饪批次比较RGB基线、加入深度以及Large/Small；分清菜品识别、重量、营养估算和建议效果。
