# 桌面食物持续监测样机硬件需求及询价书

Group 2　版本 2.0　2026年9月15日　数量 1 台

## 1 项目用途与本次询价

我们正在开发一套食物数量与营养参考监测系统，用于减少供餐时的空盘和过量补餐，并支持学校配餐观察及个人餐食记录。本次希望制作**一台可独立放在桌面上演示的完整硬件样机**，邀请贵司按本文基准提供供货、结构加工、配电装配与基础联调报价。

在自助餐演示中，工作人员将装好食物的餐盆放到设备上，此后餐盆保持原位供餐。底座持续称重，顶部相机持续提供彩色和深度数据。我方计划通过软件把菜品身份、有效余量及取用趋势结合起来，在屏幕和网页上显示状态，并给出补餐时机与数量建议。补充食物后，设备继续测量变化。**我们需要的是原位持续监测，不是只在出餐和回盘时分别扫描一次。**

### 同一台设备的演示方式

| 场景 | 放在设备上的物品 | 我方软件计划提供的反馈 |
|---|---|---|
| 供餐演示为主 | 一只盛装已登记菜品的供餐盆 | 当前余量、消耗趋势、补餐建议及补充后的变化 |
| 学校配餐演示 | 一份匿名样本餐或分餐容器 | 份量、参考食物组及剩余记录 |
| 成年人个人餐食演示 | 一只餐盘，可逐项加料 | 已记录份量、参考营养和总剩余；估算明确标识 |

三种配置在同一台设备上轮流演示。本次只做**一个独立称重位置、一台相机和一台主机**，不包含多餐位布线、真实餐厅安装或量产。相机与重量不承担隐藏配料、油盐化学成分或人体健康检测。

### 主报价范围

请以“**采用现成电子模块，完成一台有外壳、已配线、可采集原始数据的硬件样机**”作为主报价。贵司负责依据本文提出结构与电气装配方案，经确认后采购、加工、组装并完成约定的硬件测试。AI模型、补餐算法、业务后台、正式界面和扫码点餐由我方开发。

本文尺寸与性能数值是用于统一报价的技术目标，尚非已测结果。请在回复中逐项说明“满足／偏离／需进一步确认”，并提供替代数值、理由和价格影响。型号替换与额外开发须单列，不默认改变基准配置。本次为询价，不构成订单或软件成果交付承诺。

## 3 机械结构与使用环境

机架、相机、屏幕和线束固定在静止底座上。餐盆或餐盘的全部重量必须通过独立称重结构传递，不能被罩壳、台边、立柱或拉紧的线束分担。外观优先哑光深色、圆角和易擦拭表面，可采用金属骨架加可拆罩壳，无需注塑开模。

| 编号 | 主报价目标 | 供方应说明或交付 |
|---|---|---|
| M01 | 建议底座外廓约450×400mm，高度不超过80mm；整机最大高度目标不超过750mm | 总装图与实际尺寸；如需调整，说明与视野、刚度、成本的关系 |
| M02 | 有效浮动承载面约350×250mm，可放GN1/3盆325×176×65mm及约24cm平底餐盘 | 餐盆与餐盘各含1只；列托板材料、厚度、重量及防滑措施；固定底板不是称重托板 |
| M03 | 工作毛重不超过5kg，包含浮动托板、垫片、容器和食物；传感器参考额定10kg | 列出固定皮重和可用食物净重；本期净重验收至3kg，且不得超工作毛重 |
| M04 | 后侧单立柱、弧形臂或相近外形；镜头光心距承载面可调450–600mm，初始约500mm | 支架锁紧方式、镜头定位和防倾倒设计；调节后保留重复定位标记 |
| M05 | 称重活动部件与外壳留有间隙，配置过载限位；正常工作载荷下限位不接触 | 剖面／装配图；不得在称重梁敏感部位钻孔，紧固按元件要求 |
| M06 | 屏幕竖向安装并朝操作者；触屏操作不使承载板与外壳接触 | 屏幕架可维护、连接器有弯曲空间；轻触后读数能正常恢复稳定 |
| M07 | 容器可取走擦洗；机盒可打开维护，外部无裸露接线和锐边 | 食品接触由容器承担；托板及垫片可拆，清洁时不冲洗电子件 |
| M08 | 电子件与食盆隔离，保留进排风；目标整机重量不超过6kg，不含食物与外置电源 | 模块布局、重量和散热说明；相机光学窗口前不加未经验证的透明板 |
| M09 | 室内水平桌面，环境15–35°C、无凝露；称重验收在20–30°C稳定环境进行 | 使用与存放条件；常规报价不含户外、防水认证、保温或加热功能 |

主报价使用室温测试物。热盘适应性作为第10节选配O03单列：可提出隔热结构，并报告约60°C容器底部条件下的漂移和材料温升；此项不是食物温度检测功能。未经该项验证，不把样机标为可直接用于热保温餐台。

## 4 称重模块与量测目标

称重是有效余量的主要来源。首选适用于上述平台尺寸的单点式全桥称重传感器及数字ADC；不要仅按额定公斤数选用没有平台偏载依据的普通小梁。10kg额定量程、24位ADC或显示1g均不等于整机准确度。

|---|---|---|
| W01 | 一个独立测量通道；参考10kg四线全桥传感器，工作毛重≤5kg | 提供型号、额定平台尺寸、安装图、激励电压、灵敏度和接线定义 |

| W03 | 在扣除固定皮重后，0–3kg净重范围内，中心静态误差目标为±5g | 校准后以独立检查点验收，记录参考质量、均值、误差及环境 |
| W04 | 显示步进1g；重复放置同一500g参考质量10次，稳定读数极差目标≤3g | 报告每次结果，不能通过显示舍入隐藏更大的实际波动 |
| W05 | 500g参考质量放中心及四角有效测试位，位置间稳定读数差目标≤5g | 四角位置距承载面边缘约30mm；提供位置示意与结果 |
| W06 | 放稳物品且手离开后，目标2秒内进入稳定状态 | 稳定判定条件及滤波设置需说明；触碰期间允许标记无效 |

| W08 | 预热后以1kg初始稳定示值为基准，室温恒载2小时内最大偏移目标≤10g | 禁用静默自动去皮；记录预热时间、温度、供电和读数曲线 |
| W09 | 容器可登记皮重；去皮必须通过明确操作触发 | 交付基础标定系数及恢复方法，我方另行实现容器／批次业务逻辑 |

基础标定和硬件验收可使用供方例程；我方会在收到样机后复核，并开发稳定检测、移盘／加料判断及后续数据处理。若任一目标需要更换传感器或结构，请报实际可达到的值及对应价格。

**建议检查点：**0、100、500、1000、2000、3000g，分别加载与卸载，各至少3轮；参考砝码的不确定度应明显小于5g误差限。校准点与最终检查点至少有部分不同，保留全部原始记录。若皮重加3kg会超5kg，应先调整托板／容器或申报偏离，不能超量程验收。

## 5 顶部相机与固定照明

主报价采用一台**Orbbec Gemini 2完整RGB-D相机**，保持原厂光学与电路。Gemini335或其他相机仅作为单列替代报价，不因外形相似就默认等同。相机负责提供图像、深度和标定数据，我方负责食物识别与后续几何处理。

| 编号 | 主报价目标 | 供方确认内容 |
|---|---|---|
| C01 | 连续获取RGB与原始深度；最低目标RGB≥1280×720、深度≥640×400，两流均≥15fps | 提供SDK实际支持的同时输出组合；另列可用的更高分辨率模式 |
| C02 | 可取得深度单位、无效值定义、相机内参、必要外参及时间戳 | 原始深度不能仅用伪彩色图或普通录像替代 |
| C03 | 在指定安装高度内，目标承载区处于RGB及深度共同可用视野 | 用平面标定板检查边界、角落及缺测位置；报告实际设置 |
| C04 | 相机支架可锁紧，可使用原厂1/4-20或M3安装点 | 螺丝长度和方向按厂家图纸，不拆机改镜头，不让支架遮挡发射／接收窗口 |
| C05 | 感测头有外观罩壳和必要通风，RGB／IR视线开放 | 普通玻璃或亚克力不可直接封住光学窗口；若另加窗口需单独验证 |
| C06 | 采用完整USB3数据线，支持5Gbps连接，线长优先≤1m | 原厂接头与接口固定防松，线沿静止立柱走，不拉扯称重托板 |
| C07 | RGB-D对齐可通过可用SDK方式完成，保留配置与标定版本 | 说明硬件／软件对齐条件；不要求重建整间房间或多视角三维模型 |
| C08 | 提供相机在目标Pi系统上的枚举及连续采集测试 | 记录系统、SDK、固件、流参数和断连情况；PC测试不能替代Pi测试 |

## 7 统一供电与线束要求

成品应由**一只外置成品适配器，经一根低压电源线进入底座**供电。市电留在外置适配器内，底座内完成低压保护和分路。参考12V输入，分为Pi供电板支路与相机／照明Hub支路；不将两个稳压模块的5V输出直接并联。

| 编号 | 供电与配线目标 | 必须确认的细节 |
|---|---|---|
| P01 | 外置12V适配器，参考额定≥60W，香港使用的英规成品电源线 | 提供厂商型号及额定值；额定功率应≥完整负载最大实测功率的1.25倍，不足则升级并列差价 |

| P03 | 独立供电USB3 Hub，参考ORICO-BT2U3-7AB或经说明的亚博同类产品 | 同时传数据与供电；相机口供电能力至少5V／1.5A；列每口和总额度 |
| P04 | 相机、两条灯及屏幕按实际选择分配支路 | 列出启动和持续负载预算；更换屏幕后重算，不默认Pi USB可带全部设备 |
| P05 | Hub上游不向Pi反向供电 | 提供说明及检查记录；不得依赖剪开普通USB线的临时Y接法 |

## 8 采集接口 交付资料与责任范围

我们需要能够自行继续开发和维护的硬件平台。供方负责基础驱动、接口连通、出厂基础标定和本文约定的硬件测试；我方负责菜品目录、稳定状态和物理事件业务处理、模型训练、几何／营养估算、补餐逻辑、后台和正式网页。

| 数据或接口 | 基础交付要求 | 后续由我方实现 |
|---|---|---|
| 称重 | 给出ADC／数字接口、单位、原始值与基础标定系数；能连续读取 | 不稳定读数处理、去皮操作规则、容器绑定、取用／加料／移盘事件 |

# 食物持续监测设备硬件制作询价

## 1 项目与制作范围

我们正在开发一台用于学生项目演示的桌面食物监测设备。以自助餐为主要场景：工作人员把餐盆放上设备，餐盆保持原位供餐；底座持续称重，顶部相机观察食物变化，后续由我方软件显示余量并提供补餐建议。同一台设备也会用于学校配餐和个人餐食记录演示。

**本次希望贵司交付一台外形完整、部件已安装、内部接线已集成的硬件样机。**整个项目只做一个独立称重位置，食物在设备上持续被监测，无需每次取餐后搬去另一个位置扫描。

**贵司负责：**电子部件配套、底座／立柱／外壳等结构制作、部件固定、内部配电及全部接线装配。

**我方负责：**系统安装、驱动与采集程序、称重校准、AI模型、后台及网页、软件调试和性能测试；这些工作无需贵司开发或提供报告。

## 4 必要的集成要求

- **称重受力分开：**相机、屏幕和立柱固定在静止机架；餐盆重量经过称重传感器。浮动托板不碰外壳，线束不牵拉托板。
- **单线供电：**外置适配器使用香港适用的英规电源插头；机内有低压总开关、保护及可靠固定。USB Hub不能向Pi反向供电。
- **可维护、便于清洁：**外壳圆角、内部留散热空间，餐盆可取走清洗；相机镜头／红外窗口不被罩壳遮挡，电子件避免接触食物和清洁用水。
- **方便我们后续开发：**保留模块原厂接口，提供实际部件型号和简明接线对应即可；系统、程序和校准由我方自行处理。
