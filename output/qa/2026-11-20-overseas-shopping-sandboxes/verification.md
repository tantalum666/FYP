## Independent refund verification

The existing [read-only Stripe verifier](../../../desk-companion/scripts/verify_stripe_sandbox_checkout.py) accepts an optional `--full-refund-file` with a private JSON `id`. It reopens the original Checkout, PaymentIntent, Charge and the specified Refund in the named test account. It checks both payment references, amount, currency, terminal refund status and the Charge's cumulative refunded amount. Its original paid-only check continues to require zero refunded amount. This supports one full refund in one operation. Ordinary Alice chat still has the existing WooCommerce checkout authority. [Stripe Refund retrieval](https://docs.stripe.com/api/refunds/retrieve).

Ten new checks cover successful readback, paid-only compatibility, incomplete and partial refunds, wrong currency, unrelated payment references, live-mode mismatch, disagreement between the Charge and Refund, and an explicit refund file missing its ID. The normal CLI also read the new provider records with the expected merchant reference, amount and currency. The operator saw exactly one linked refund. Stripe's hosted receipt showed the original test Visa and zero adjusted total. It produced no shipment or bank charge.

The first Amazon Pay read exposed a real compatibility issue. The original checker required a `ch_` Charge prefix and a `re_` Refund prefix. The provider returned a Charge beginning with `py_` and a Refund beginning with `pyr_`. The read-only checker now accepts a safe single path segment and verifies the resource type and exact cross-references on the provider response. The original failed check issued zero refunds. Only the verified retry created the refund. Two new regression checks cover wallet identifiers, wrong object types and invalid lookup paths. Those two and the affected card-format compatibility check passed. The final CLI read the original wallet purchase and terminal refund successfully. Ruff passed. The prior payment and native acceptance records were reused. The installed Woo adapter remains scoped to its existing test Visa fixture.
