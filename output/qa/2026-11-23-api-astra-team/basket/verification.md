Candidate `3c5358d13205aee5da2551d4a97119bb32e8d4c0` passed the 23 November 2026 mixed-basket checks against a copy of the real FYP test merchant. ## Changes that held the total constant

- Two line subtotals moved from HK$8 + HK$17 to HK$9 + HK$16. Woo kept HK$33 as the total. Alice explicitly asked to review the changed detail, replaying the older approval left the new review pending, and declining produced zero Stripe payment records. [Equal-total price changes](same-price-lines.json).
- A clone-only hook substituted a genuinely different same-priced catalog product at checkout, before the gateway. The original approval reached no merchant payment mapping and produced zero Stripe intents or charges. An explicit new request naming the replacement produced a distinct unapproved HK$33 review, which the owner declined. **The first response after this late substitution is generic.** Alice reports unmatched shop and payment records, leaving the buyer to request a fresh selection. This test verifies refusal of the substitution and an explicit replacement review. [Late replacement](late-substitution.json).
- Depleting all tissue stock between the original quote and confirmation made the whole review unavailable. A fresh request also produced no partial basket and no new intent or charge. The actual Store API catalog checks covered an exact variable-product SKU, an ambiguous variable parent, a missing second item, normalized duplicate SKU quantities, the 99-unit limit and the previous one-product request format. [Stock loss](stock-lost.json) · [Catalog checks](catalog-matching.json).
