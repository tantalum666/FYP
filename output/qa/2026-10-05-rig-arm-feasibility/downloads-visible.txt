Firmware#

Use Luwu Tools and select English to flash international firmware. The Chinese page flashes domestic (China) firmware. Choose the correct model and an available release before connecting to the serial port. Read the installation guide.

Mechanical files and kit resources#

The Chinese assembly guides point to LuwuDynamics on MakerWorld for model files. Select the exact robot and hardware revision. Check the included assembly diagrams, BOM, orientations and fastener list before printing.

The structural model does not replace the electrical wiring diagram. Use the drawing supplied with your kit or ask official support for the matching revision.

Source code#

RIG-Omni source repository contains shared services and model-specific board directories.

Documentation baseline#

The public source repository provides the firmware code and development instructions. See Versions and source notes for the distinction between source versions and published firmware.
